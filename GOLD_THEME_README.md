# WebKitty Gold Edition

This version includes a real selectable **Gold Edition** color theme.

- Gold theme CSS: `includes/css/colors/gold.css`
- Background: `includes/assets/backgrounds/ps4-bg.jpg`
- Gold is the default color theme for a fresh browser/localStorage profile.
- Existing WebKit/exploit files are preserved.
- Settings > Theme > Gold Edition can be used to select it.
